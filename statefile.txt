    2. Built Basic File Parser:
       - File: src/static_analysis/parser.py
       - LogEntry class for structured log data
       - LogParser class with regex-based parsing
       - Methods: parse_file(), get_unique_ips(), get_summary(), etc.
       - Tested successfully: 53 entries parsed, 0 errors

    3. Implemented DSA Structures:
       - File: src/static_analysis/dsa_structures.py
       
       a) HashMap (Custom Implementation):
          - Separate chaining for collision resolution
          - Auto-resize with load factor
          - Methods: put, get, increment, get_top_n, etc.
          - Use case: IP frequency tracking
       
       b) Trie (Prefix Tree):
          - Path-based tokenization
          - Methods: insert, search, starts_with, find_suspicious_patterns
          - Use case: URL/endpoint pattern matching
          - Detects: path traversal, suspicious file access
       
       c) Graph (Adjacency List):
          - Directed graph with weighted edges
          - Methods: add_edge, bfs, find_connected_components
          - Use case: IP-to-endpoint relationship analysis
          - Detects: scanning behavior, frequent connections

[✓] DAY 2 COMPLETED (December 6, 2025)

    1. Created Static Detector:
       - File: src/static_analysis/static_detector.py
       - Threat and DetectionResult classes for structured output
       - DetectionConfig for configurable thresholds
       - AttackPatterns with regex patterns for SQL injection, XSS, path traversal
       
    2. Detection Rules Implemented:
       - BRUTE_FORCE: Multiple failed logins from same IP within time window
       - SQL_INJECTION: Pattern matching for SQL keywords and injection syntax
       - XSS: Detection of script tags, javascript:, event handlers
       - PATH_TRAVERSAL: ../ patterns, %2e encoding, sensitive file access
       - PORT_SCAN: High out-degree in Graph (many endpoints in short time)
       - DDOS: Multiple IPs hitting same endpoint simultaneously, 503 errors
       - OFF_HOURS_ADMIN: Admin endpoint access outside 6AM-10PM
       - SUSPICIOUS_TOOL: Detection of sqlmap, nmap, nikto, curl user agents
       
    3. DSA Integration:
       - HashMap: IP frequency tracking (get_top_n for suspicious IPs)
       - Trie: Endpoint pattern analysis (find_suspicious_patterns)
       - Graph: Connection analysis (get_high_degree_nodes for port scanning)
       
    4. Main Entry Point:
       - Function: run_static_analysis(filepath)
       - Ready for GUI integration by Samrah
       - Returns DetectionResult with threats, summary, statistics
